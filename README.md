# Foreman

Landing page, support, privacy policy and terms for **Foreman**, a job tracker, quoting and invoicing app for tradespeople (iPhone, iPad). Served by GitHub Pages at <https://azun-k2.github.io/foreman/>.

`privacy_policy.html` only redirects to `privacy.html` (the 1.0 site had both). The app links `privacy.html`, `support.html` and `terms.html`: keep those paths.
Icons are regenerated from the app with `../_tools/make-site-icons.py` run in `../Foreman`.
The store badges and the "More apps" grid are written by `../_tools/site-family.py apply`.
